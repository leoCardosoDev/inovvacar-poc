# Imagens oficiais de veículos

Este diretório reúne arquivos locais de referência visual para o portfólio informado no contexto da Inovva Car.

- A origem de cada arquivo está em `fontes-oficiais.json`.
- O acervo não confirma disponibilidade, preço, ano da unidade, quilometragem ou condição comercial.
- O uso público deve ser validado quanto a autorização, versão e direitos de reprodução.
- O nome do arquivo usa português do Brasil em `kebab-case`; nomes oficiais de marcas permanecem reconhecíveis.
- `ferrari-portofino-vermelha.webp` é o asset vermelho fornecido para a Hero Section institucional; ele substitui a imagem-base clara usada apenas como referência oficial.
- `fiat-strada-branca.webp` é o asset do Strada branco fornecido para a composição da Hero; ele substitui a antiga imagem de logotipo que estava sendo usada por engano.
- `mercedes-c180-prata.webp` é o asset do C 180 prata fornecido para destacar um único carro na composição da Hero.
- O Volvo XC40 está registrado no manifest com download pendente porque o CDN oficial bloqueou o acesso automatizado neste ambiente.
