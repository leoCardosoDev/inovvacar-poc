# Assets do Design System

Esta pasta separa intenção visual, referências e conteúdo aprovado. Antes de adicionar um arquivo, classifique-o pela tabela:

| Pasta | Entra aqui | Não entra aqui |
| --- | --- | --- |
| `brand/` | Logos oficiais da Inovva e da Inovva Car | Logos redesenhados, variações com efeitos ou fundos falsos |
| `references/` | Amostras copiadas das referências estudadas | Assets finais da Inovva Car ou fotos de veículos em operação |
| `mood/` | Atmosfera e direção visual dos espécimes | Conteúdo que será publicado no site |
| `institutional/` | Assets aprovados para o futuro site institucional | Referências externas ou assets de veículos |
| `showroom/` | Assets aprovados do futuro showroom e dos veículos | Imagens de estudo de Iron Man, Thor ou Cogni |

Regras obrigatórias:

1. Usar nomes em português, sem acentos, em `kebab-case`.
2. Manter nomes oficiais de marcas somente quando forem necessários para identificar a origem.
3. Confirmar que a extensão corresponde ao formato real.
4. Atualizar `manifest.json` quando surgir uma nova categoria ou exceção.
5. Nunca apontar um componente para um arquivo fora de `design-system/assets/`.
